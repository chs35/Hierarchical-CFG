# 생성물 전수 육안 평가 보고서 (Claude)

- 작성: 2026-10-13, Claude (Opus 5.5) 서브에이전트 260개가 이미지를 직접 보고 채점, 메인 에이전트가 집계·분석
- 대상: `runs/{모델}/hcfg/{샘플링 방식}/w1_n_w2_m/{제어 프롬프트}/seed0/` 의 **25,900장 전부** (seed0, 셀당 20장)
- 이 문서에는 **평균 점수만** 싣는다. 이미지별 점수와 짧은 관찰 메모는 `docs/sample_observation_scores_CLAUDE.csv`(25,900행)에 있다.
- 표기: **D** = 도메인 정합성(↑ 좋음), **C** = 제어성(↑ 좋음), **K** = 붕괴(↓ 좋음, 높을수록 결함이 심함), **균형** = (D + C + (10 − K)) / 3 (비교 편의를 위한 보조 지표)

## 0. 요약

1. **일반 CFG(w1 = w2)에서는 LoRA 계열 모델 모두 제어성이 거의 없다.** w1 = w2 평균 C: vanilla 0.83, DreamBooth 0.94, CA-LoRA 1.90, CA-LoRA+dropout 3.21. **w1 > w2로 refine 항을 키우면 제어성이 크게 회복**된다(각각 3.45 / 4.42 / 5.76 / 5.79). 이때 도메인 손실은 0.4~1.1점 수준이다. 계층적 CFG의 핵심 주장은 육안 평가로도 지지된다.
2. **붕괴는 거의 전적으로 w2가 결정한다.** w2 ≥ 4에서 녹색/청록 색조와 좌측(이후 양측) 테두리 노이즈 띠가 나타나고, w2 = 7~10에서는 형광 녹색 필터·포스터라이즈·엠블럼 중복으로 악화된다. w1이 붕괴에 미치는 영향은 작다. 반대로 CA-LoRA 계열은 w2 = 1에서 회색·세피아 연무로 장면이 씻겨 나가거나 형체가 사라지는 별도의 붕괴가 있다.
3. **도메인 정합성은 대부분 w2 = 2에서 최고**이고, 그보다 크면 결함 때문에 오히려 떨어진다. 예외로 CA-LoRA+dropout 기본형은 w2 = 7, TI는 w2 = 4에서 최고다.
4. **모델 간 비교 (기본형 전체 평균)**
   - 도메인: vanilla 7.22 ≈ DreamBooth 7.12 > dropout 6.06 > CA-LoRA 4.85 > TI 3.62
   - 제어성: TI 5.09 > dropout 3.35 > CA-LoRA 2.81 > DreamBooth 2.05 > vanilla 1.65
   - 붕괴: dropout 3.38 ≈ DreamBooth 3.48 < vanilla 3.62 < TI 4.37 < CA-LoRA 5.11
   - **"도메인 D ≥ 7, 붕괴 K ≤ 3"을 지키면서 얻을 수 있는 최대 제어성**은 DreamBooth (7, 2)가 C = 5.76으로 단연 가장 좋다.
5. **샘플링 방식 비교**
   - **제어성 대안형**은 CA-LoRA에서 제어성을 크게 올린다(평균 C 2.81 → 4.10, (4, 2)에서 C 7.87). vanilla에서는 이득이 작다.
   - **도메인 대안형**은 w2 ≤ 2에서는 기본형과 비슷하다. w2 ≥ 4에서는 모든 모델에서 붕괴가 더 심해 전체 평균으로는 기본형보다 나쁘다. 특히 CA-LoRA+dropout에서 크게 나쁘다(균형 5.35 → 3.59).
6. **제어 프롬프트 난이도** (전 모델·방식·셀 평균 C): night 1.47 < suv_motorcycle 2.26 < snowy 3.07 < foggy 3.32 < green_truck 3.43.
   - "in dark night"는 TI와 높은 w1을 제외하면 거의 반영되지 않는다.
   - "파란 SUV"는 전 구간에서 거의 한 번도 정확히 생성되지 않았다.
7. **Diff_Null 분리 실험(λ)**: Diff⊥를 제거해도(λ = 0) 붕괴가 줄지 않았다(기본형 w2 = 4: K 4.52 → 4.47). 기존 실험 설계의 판정 규칙("λ = 0에서 붕괴가 완화되지 않으면 실험 실패")에 따르면 가설은 지지되지 않는다. 기본형 λ = 5(증폭)는 오히려 붕괴를 낮췄지만(K 3.63), 도메인 대안형 λ = 8은 붕괴를 높여(K 5.21) 방향이 일관되지 않다.

## 1. 평가 방법

### 1.1 대상 (유효 폴더만)

| 모델 (파인튜닝 방식) | 평가한 샘플링 방식 |
|---|---|
| `textual_inversion` (TI, 통제군) | basic |
| `dreambooth_lora` (DreamBooth LoRA r=64) | basic |
| `vanilla_lora` (vanilla LoRA r=64) | basic, alt_domain, alt_refine |
| `ca_lora_style` (style CA-LoRA) | basic, alt_domain, alt_refine, basic_split, alt_domain_split |
| `ca_lora_style_dropout` (style CA-LoRA + condition dropout, 통제군) | basic, alt_domain |

- 풀 그리드 방식: (w1, w2) ∈ {1, 2, 4, 7, 10}², 25셀 × 5 프롬프트 × 20장 = 2,500장/방식
- split 방식: w1 = 7 고정, basic_split 4셀(400장), alt_domain_split 5셀(500장)
- `split_check*` 등 그 외 폴더와 `hcfg_smoke_*`는 제외했다.
- 제어 프롬프트 c_refine = c + 아래 문구. c는 `Photorealistic first-person urban street view`이고, DreamBooth는 `... with sks style`, TI는 `... with S* style`이다.
  - snowy: `, in snowy weather`
  - foggy: `, in foggy weather`
  - night: `, in dark night`
  - green_truck: `, a green truck on the road`
  - suv_motorcycle: `, a blue SUV and a red motorcycle on the road`

### 1.2 채점 기준 (이미지마다 항목별 0~10 정수)

- **도메인 정합성 (D)**: 학습 이미지 10장(Cityscapes)과 같은 데이터셋 사진처럼 보이는지 본다. 기준은 대시캠 1인칭 시점과 보닛·엠블럼, 독일 도시 거리, 차분한 저채도 실사 색감이다. 제어 프롬프트가 요구한 변화(날씨·밤·차량) 자체로는 감점하지 않는다.
- **제어성 (C)**: 프롬프트별 기준표로 채점했다.
  - green_truck: 화면 전체에 씌워진 녹색 필터는 차체 색으로 인정하지 않는다.
  - suv_motorcycle: 두 요소(파란 SUV, 빨간 오토바이)에 각각 절반씩 배점한다.
  - foggy: 단순히 흐리거나 대비가 낮은 것은 안개로 인정하지 않는다.
- **붕괴 (K)**: 의도하지 않은 결함의 정도. 0 = 없음, 1~3 = 경미, 4~6 = 뚜렷, 7~9 = 심각, 10 = 완전 붕괴.
  - 대상 결함: 테두리 노이즈/색 줄무늬, 녹색(청록) 필터, 형체가 사라진 단색 화면, 과포화·포스터라이즈, 구조 왜곡, 반복 패턴
  - 보닛·엠블럼 같은 Cityscapes 고유 특징은 결함으로 보지 않는다.

### 1.3 절차

- **작업 단위**: (모델, 샘플링 방식, 제어 프롬프트, w1 행) 하나를 서브에이전트 1개가 맡는다.
  - 한 에이전트는 w2 = 1~10의 5셀 100장을 본다(split은 해당 방식·프롬프트의 전체 셀).
  - 모두 260개이며, **각 에이전트는 제어 프롬프트 하나만 담당**한다. 같은 행의 w2 변화를 한 에이전트가 함께 보게 해서 셀 간 상대 비교의 일관성을 높였다.
- **이미지 제시 방식**: 원본 1024px를 500px로 줄여 4장씩 2×2 그리드로 묶고, 칸마다 파일 번호를 붙였다. 차량 색처럼 축소본으로 판단이 어려울 때만 원본 PNG를 열게 했다.
  - 테두리 노이즈와 녹색 필터가 축소본에서도 명확히 보이는지 사전에 확인했다.
- **기준 이미지**: 각 에이전트는 학습 이미지 10장을 모은 참조 시트를 먼저 본다.
- **편향 방지**: 가중치나 방식 이름으로 점수를 짐작하지 말고 보이는 것만 채점하도록 지시했다.
- **실행 환경**: 동시 실행 서브에이전트는 최대 48개(제한 50 이내)였고, 모델은 모두 Opus 5.5다.
- **검증**: 모든 결과 파일이 셀당 20장, 0~10 정수인지 자동 검사했다(문제 0건). 메인 에이전트가 무작위로 고른 그리드를 직접 보고 점수와 대조했다. 예: DreamBooth (7,1) snowy는 D 8~9 / C 10 / K 0, vanilla (1,1) night는 C 0으로 실제 이미지와 일치했다.

### 1.4 해석 시 주의

- **에이전트 간 보정 차이**: 같은 행(w1 고정, w2 변화) 안의 비교가 가장 신뢰할 만하다. 서로 다른 에이전트가 채점한 셀(다른 w1 행, 다른 모델·방식) 사이의 0.5점 안팎 차이는 노이즈로 보는 것이 안전하다.
- **표본 크기**: seed0 한 개, 셀당 20장이다. 셀 평균의 표본오차는 대략 ±0.3~0.6점이다.
- **녹색 필터의 이중 반영**: 녹색 필터는 붕괴(K)와 도메인(D, 색감)에 함께 반영된다. 높은 w2에서 D가 떨어지는 데에는 이 영향이 섞여 있다.
- **LLM 육안 채점의 한계**: 계획된 정량 평가(P(Cityscapes|x) 분류기, zero-shot 분류/검출)를 대체하지 않는다. 그 결과가 나오면 서로 대조해야 한다.

**해석**

- **Textual Inversion**: 도메인 과소적합이 뚜렷하다(평균 D 3.62, 모든 셀에서 ≤ 5.5).
  - 보닛·대시캠 시점이 거의 재현되지 않고, w2가 낮으면 CG·스케치·일러스트풍이 많다.
  - 제어성은 가장 높다(C 5.09). w1 ≥ 4에서는 w2 = 4까지도 제어가 유지되어, **w1 < w2 근처에서도 제어성이 남는 유일한 모델**이다.
  - 그런데도 w2 ≥ 7에서는 거의 모든 이미지에 강한 녹색 필터가 씌워진다(w2 = 10: K 7.89). Diff_Null = 0인 TI에서도 녹색 붕괴가 나타나므로, **녹색 붕괴의 원인이 Diff_Null만은 아님**을 시사한다.
- **DreamBooth LoRA vs vanilla LoRA**: 도메인 흡수는 거의 같다(7.12 vs 7.22). 둘 다 w1 = w2에서 제어성을 거의 잃는다(0.94 vs 0.83).
  - 기존 관찰 노트의 "DreamBooth는 w1 = w2에서도 제어성이 살아 있다"는 이번 전수 평가에서는 **재현되지 않았다**.
  - 다만 w1 > w2에서 DreamBooth의 제어성 회복이 더 크고(4.42 vs 3.45), 붕괴도 더 낮다. 그 결과 높은 도메인을 유지하는 영역의 trade-off는 DreamBooth가 가장 좋다(4.2절).
- **style CA-LoRA**: 평균 도메인이 낮고(4.85) 붕괴가 가장 심하다(5.11). 원인은 양 끝단에 있다.
  - w2 = 1: 회색·보라색 연무로 장면이 씻겨 나가고 일부는 빈 화면이 된다.
  - w2 ≥ 7: 형광 녹색 포스터라이즈
  - 중간 영역(w2 = 2~4)에서는 D 6~7, 제어성은 vanilla/DreamBooth보다 높다(w1 = w2에서 C 1.90).
- **style CA-LoRA + condition dropout**: 기본형에서는 **높은 w2에서도 붕괴가 훨씬 약하다**(w2 = 10: K 5.24 vs CA-LoRA 8.13). 도메인도 유지된다(w2 = 7~10: D 6.5~7.1). 녹색 필터 대신 상하단 줄무늬와 약한 청록 색조가 주된 결함이다.
  - 기존 노트의 "CA-LoRA와 전반적으로 유사"와 달리 기본형에서는 뚜렷이 다르다.
  - 도메인 대안형으로 바꾸면 CA-LoRA와 똑같이(또는 더 심하게) 붕괴한다(w2 = 10: K 9.03).
  - 가설: dropout으로 학습된 ε(FT, φ)가 이미 도메인 쪽으로 이동해 있어, 기본형(앵커 = ε(FT, φ))에서는 큰 w2가 덜 필요하다. 반대로 Base 앵커에 w2·Diff_Null을 더하는 대안형에서는 그 차이가 증폭된다. 진단 지표 ‖Diff_Null‖ / ‖G_domain‖과 대조가 필요하다.

## 3. 샘플링 방식별 비교

T1(위)의 방식별 행과 4장 그리드를 함께 보면 다음과 같다.

| 모델 | 기본형 → 도메인 대안형 (ΔD / ΔC / ΔK) | 기본형 → 제어성 대안형 (ΔD / ΔC / ΔK) |
|---|---|---|
| vanilla LoRA | −1.16 / −0.20 / +0.65 | −0.04 / +0.14 / +0.34 |
| style CA-LoRA | −0.43 / −0.32 / +0.35 | −0.58 / **+1.29** / +0.49 |
| style CA-LoRA + dropout | **−2.08** / −1.02 / **+2.15** | – |

**도메인 대안형** (ε(Base, φ) + w1·G_refine + w2·G_domain,hybrid)

- w2 ≤ 2에서는 기본형과 거의 같거나 도메인이 약간 높다. 예: CA-LoRA (1, 2): D 7.7 vs 7.3, dropout (1, 2): D 7.2 vs 6.2.
- **w2 ≥ 4부터 붕괴가 기본형보다 빠르게 커진다.** w2·Diff_Null이 함께 증폭되기 때문으로 보인다.
- w2 = 10에서 CA-LoRA는 K 8.81 vs 8.13, vanilla는 7.00 vs 6.19, dropout은 9.03 vs 5.24다.
- 따라서 "도메인 대안형은 양호"라는 기존 관찰은 **w2 ≤ 2 영역에 한해서만** 유효하다. 높은 w2와는 함께 쓸 수 없다.
- 낮은 w2에서 trade-off는 기본형과 비슷하다(4.2절 표의 제약 하 최대 C가 비슷).

**제어성 대안형** (ε(FT, φ) + w1·G_refine^Base + w2·G_domain)

- **CA-LoRA에서는 확실한 이득이 있다.** w1이 커질수록 C가 기본형보다 빠르게 오른다.
  - w1 = 10 행 평균 C: 6.66 vs 5.02
  - (4, 2): C 7.87(기본형 5.0), (7, 1): C 8.8

## 5. 제어 프롬프트별 경향

- **night (평균 C 1.47)**: 가장 어렵다. vanilla 기본형 평균 C는 0.21이다.
  - LoRA 계열에서 밤 표현이 나온 경우는 대부분 w2 = 1이고, 그마저 안개 낀 어스름 수준이다.
  - w2 ≥ 4에서는 거의 100% 낮 장면이다.
  - TI는 w1 ≥ 7, w2 ≤ 4에서 C 5~7.5로 예외적이다.
- **suv_motorcycle (2.26)**: 빨간 오토바이(스쿠터)는 낮은 w2에서 종종 나오지만, **파란 SUV는 전 구간에서 거의 생성되지 않는다**. 파란 해치백이나 파란 오토바이로 색이 뒤바뀌는 경우가 많다. SDXL의 다중 객체·속성 결합 한계로 보이며, TI에서도 C 3.59에 그친다.
- **snowy (3.07) / foggy (3.32)**: w1 > w2에서 잘 반영된다(최고 C 9~10).
  - foggy는 w2 = 1의 연무 붕괴와 잘 구분되지 않는다. 안개가 강한 셀일수록 보닛이 사라져 D가 낮아지는 경향이 있다.
- **green_truck (3.43)**: 녹색 "밴·승용차"로 반영되는 경우가 많아 부분 점수(5) 위주다.
  - 높은 w2의 녹색 필터는 제어로 인정하지 않았기 때문에, 녹색 필터 영역에서는 C가 오히려 낮다.
- 기존 노트의 "날씨보다 차량 제어가 어렵다"는 suv_motorcycle에는 맞지만, 이번 평가에서 **가장 어려운 조건은 night**였다.

- **제거 vs 기준 (λ = 0 vs 1)**: 기본형 w2 = 4에서 붕괴가 그대로였다(K 4.47 vs 4.52). 도메인은 약간 낮아졌다(6.08 vs 6.43). w2 = 2에서도 붕괴는 줄지 않았다(3.24 vs 2.97). 에이전트 관찰에서도 "λ = −1과 λ = 0은 거의 같은 장면, 녹색 색조·테두리 노이즈 공통"이라는 기술이 반복된다. → **Diff⊥ 제거로 붕괴가 완화되지 않는다.** 설계 문서의 판정 규칙상 "실험 실패"에 해당한다.
- **대조 (λ = −1)**: λ = 0과 사실상 같다(K 4.78).
- **증폭**: 결과가 방식에 따라 반대로 나왔다.
  - 기본형 λ = 5: 오히려 붕괴가 줄었다(K 3.63). 도메인은 소폭 올랐고(6.56), 제어성은 약간 내려갔다(4.59).
  - 도메인 대안형 λ = 8: 붕괴가 늘었고(5.21) 도메인과 제어성도 하락했다.
  - 따라서 "Diff⊥가 붕괴의 원인"이라는 가설은 지지되지 않는다.
- **도메인 대안형 w2 = 2**: λ = 0/1이 기준(λ = 2)보다 제어성이 약간 높고(7.00/6.81 vs 6.21), 붕괴는 같다.
- 결론적으로 붕괴(녹색 필터·테두리 노이즈)는 Diff⊥ 성분보다 **w2 자체의 크기**와 더 강하게 연동된다. Diff_Null = 0인 TI에서도 같은 녹색 붕괴가 관찰된 것(2장)과도 일관된다.

## 7. 기존 육안 관찰 노트(저자의 일부 샘플 관찰 메모, 레포 미포함)와의 대조

| 기존 관찰 | 이번 전수 평가 |
|---|---|
| w1 ≥ w2에서 제어성이 돌아옴, 상대 크기가 중요 | **지지.** 단, w2 ≥ 7이면 w1 = 10이어도 회복이 제한적이다. |
| w2 = 1에서 도메인 정합성이 사라짐, 도메인은 w2에 비례 | **부분 지지.** w2 = 1은 CA 계열·TI에서 낮다. vanilla/DreamBooth는 w2 = 1에서도 D 6~8이다. 도메인은 w2 = 2 부근에서 정점이고 이후 하락한다(비례하지 않음). |
| 높은 w2에서 녹색 필터·테두리 노이즈 붕괴 | **강하게 지지.** 모든 모델에서 w2 ≥ 4부터 나타난다. |
| 날씨보다 차량 제어가 어렵다 | **부분 지지.** suv_motorcycle은 어렵다. 가장 어려운 조건은 night다. |
| (10, 7), (10, 4), (7, 4) 등이 무난 | (10, 4)·(7, 4)는 일부 모델에서 무난하다. **(7, 2)가 대부분의 모델에서 최상위**이고, (10, 7)은 붕괴 영역이다. |
| DreamBooth는 w1 = w2에서도 제어성이 살아 있음 | **재현 안 됨**(w1 = w2 평균 C 0.94). 대신 w1 > w2에서의 trade-off가 가장 좋다. |
| TI만 w1 < w2에서도 제어성이 남음 | **지지**(예: (4, 7) C 4.0, (7, 10) C 4.7). |
| CA-LoRA+dropout은 CA-LoRA와 유사 | **기본형에서는 다르다.** 높은 w2 붕괴가 훨씬 약하다. 도메인 대안형에서는 유사하거나 더 나쁘다. |
| 제어성 대안형은 좋지 않음 | vanilla에서는 지지, **CA-LoRA에서는 반대**(제어성 최고). |
| 도메인 대안형은 양호 | w2 ≤ 2에서만 양호하고, w2 ≥ 4에서는 기본형보다 붕괴가 크다. |
